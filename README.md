# TCAD 剖面編輯器 Demo（PNG 進、PNG 出，聰明游標）

介面使用 [Ant Design 5](https://ant.design)（預設主題，主色 #1677ff），版面依 [v4 介面設計](https://claude.ai/artifact/88TBoxLMjXJMCNhqqrRSuF)。

依[實作計畫 v3](https://claude.ai/artifact/KqhJMem6XE65TePBWxN1J5) 與 [prototype v3](https://claude.ai/artifact/6YygUuSbEYrrVZFYRdNcwm) 實作的展示用頁面：載入 TCAD 輸出的剖面 PNG，自動分割成區域，在圖上編輯，輸出一張尺寸與輸入完全相同的 PNG。不接宿主、不含測試。

```bash
npm install
npm run dev     # 開 http://localhost:5173
```

## 功能

- **三個方向槽**：X / Y / Z 各裝一張 PNG（預設為內建範例），各自的模型、Undo/Redo、基準；彼此不推導。
- **載入與分割**：關閉色彩管理解碼（`createImageBitmap` 的 `colorSpaceConversion: 'none'`）→ 量化調色盤（佔比 ≥ 0.05%）→ 4 鄰接連通元件（小於門檻的碎片併入鄰居，門檻可設、0 = 全部保留，顯示併入數）→ 邊界鏈 → Douglas-Peucker（0.6 px）→ 共用頂點的多邊形。簡化後每一段記下原始像素輪廓。
- **單位**：內部一律是影像 px 且永遠整數；1 px = ? nm 只影響顯示（尺規、Spec、Δ 標籤同時顯示 px 與 nm）。
- **節點**：載入時每條邊界只留代表點當節點（邊界兩端＋2 px 粗簡化的代表點，例如圓頂 fin 36 個輪廓點 → 7 個節點），其他輪廓點不顯示；在邊上雙擊新增節點（落在原始像素輪廓上，不改形狀），選取後按 Delete 刪除節點（只是不再當節點，形狀不變）；按住 V 顯示全部輪廓點。節點存在模型裡，可 Undo。
- **聰明游標（無模式）**：靠近節點 → 十字，拖節點（它與左右節點之間的輪廓依 cos 衰減跟著走，左右節點不動；按住 Shift 只動這一點）；靠近邊 → 雙箭頭，推整段平滑邊（兩端的角當錨點，Shift 只推單一小段）；區域內部 → 四箭頭，整塊搬動；空白處 → 框選。節點只在已選或游標所在的區域顯示，角畫方塊、其他畫圓點。
- **修飾鍵**：Shift 加選、Ctrl/⌘ 切換、按住 V/E/R 暫時只抓節點（含全部輪廓點）/邊/區域、雙擊或 Alt 點邊新增節點、Delete 刪除節點、右鍵區域開材質選單、Ctrl/⌘+A、Esc（先清把手再清區域）。
- **拖拉規則**：
  - 區域：第一次移動時分離與鄰居共用的頂點，只搬自己；空出的地方用回填材質（預設 VOID），搬到的地方蓋在上層；方向鍵同規則。
  - 邊／頂點，連帶推動（預設）：貼在外面、厚度均勻（≤ 16 px、變化 ≤ 2.5 px）的薄層跟著位移，最多 3 層；狀態列顯示「連帶 N 層」。
  - 邊／頂點，防穿層（關掉連帶時）：位移逐步縮小，直到與鄰居其餘邊至少留 1 px；狀態列顯示「已擋住」。
  - 往外推 N px（浮動工具列，負值往內）：已選邊沿平滑後的法線、遠離點選的那個區域移動（共用邊算游標所在那側）；連帶開時襯層以保形偏移跟著推。
  - 已選 ≥ 2 個區域時，其他區域的對應邊／頂點一起動（可關）。所有頂點夾在影像範圍內。
- **輸出**：從原圖出發，只重畫變動的區域（依 labels 精確清除舊像素）。整塊整數位移 → 像素複製；否則每段沿用原始像素輪廓（兩端位移不同時沿輪廓長度內插位移），只有新插的頂點用直線，像素中心掃描線填色、不反鋸齒。未編輯時與輸入逐像素相同。顯示相異像素數、重畫方式、材質面積帳、警告（顏色不在調色盤、重疊覆蓋、厚度 < 2 px）；下載 PNG 與材質編號圖（灰階 = 材質索引）。
- **畫面 = 輸出**：底圖預設是輸出結果（改過的地方直接是材質色）；區域輪廓與選取邊用與輸出相同的規則畫，藍線貼著像素邊；拖拉中即時重算（640×360 約 20 ms，超過 1M 像素才改成放開再算）。
- **前後比對**：左右並排，左邊原圖、右邊輸出（在右邊編輯），縮放平移同步，游標位置在左邊畫十字；任何時候按住 B 暫時看原圖；改過的地方框紅線。
- **版面**：左右欄可收合（上方工具列兩端的按鈕）；介面只顯示使用者看得懂的資訊（不顯示色碼、內部編號）。
- **材質名稱**：顏色與已知色票幾乎相同才套名稱，否則顯示「材質 n」；材質面板雙擊可改名，區域名稱跟著改。
- **其他**：浮動工具列（設 VOID、移到最上層、往外推、四方向 1 px）、相異像素標紅、區域名稱、Spec Preview 與基準差異、底圖切換（原圖／輸出／無）、縮放 1:1 / 8× / 適合視窗、平移。

## 介面

- **頂端列**：剖面方向（X / Y / Z）、檔名、復原／重做、檢視（編輯／前後比對／原圖）、上傳 PNG、匯出（PNG、材質編號圖）、操作說明。
- **左欄**：依材質分組的區域清單，可搜尋、可收合；點區域選取（Shift 加選、Ctrl 切換），點材質名稱選整組，筆形按鈕改材質名稱；只有一個區域的材質直接顯示該區域。
- **畫布**：選取後外框旁出現浮動工具列（換材質、設為 VOID、移動…、往外推…、刪除節點）；右鍵選單依點到區域／節點／邊給不同項目；「移動…」「往外推…」開輸入小窗；右下角縮放；左下角操作提示與拖拉中的狀態。
- **右欄**：「屬性」依選取內容顯示——一個區域：寬高與位置四格（px 與 nm，和比較基準不同的格子標橘色）、輸入 Δx / Δy 移動、材質、排列；多個區域：完整尺寸表＋平均列（不另外捲動）；節點：直接填 X / Y、拉動方式、刪除與回到原位；邊：總長、往外推、移動。「改動」：改動像素、改了哪些區域（點了選取）、各材質面積、輸出檢查、匯出。「顯示」：紅框、區域名稱、上色深淺、編輯方式、比例、回填材質。
- **第一次使用**：上傳頁（三個方向的槽、拖放上傳、載入設定、用範例試試看）；之後「上傳 PNG」以對話框開啟同一個畫面，也可重新分區。

## 結構

```
src/
  model/    types、geometry、ops、drag（isCorner、smoothEdgeGroup、propagateLayers、violates、outwardShifts、falloffWeights）
  raster/   quantize、components、chains（邊界鏈 → Model + 原始輪廓 + 預設節點）、importRaster、exportRaster、nodes（新增節點）、demo
  editor/   useEditor（三槽狀態、聰明游標、手勢、選取、基準、Undo）、mirror、view
  canvas/   RasterUnderlay（底圖 + 相異框線）、SectionCanvas（SVG 編輯層、浮動工具列、右鍵選單、移動面板、前後比對）
  layout/   HeaderBar、RegionList、Inspector、ChangesTab、DisplayTab、UploadPanel、HelpDrawer
  ui/       MoveForm（移動／往外推輸入）、Stat、Swatch、download
```
